Active discovery trials

One ConceptARC task at a time, DeepSeek V4.1 Flash as the student, same oracle and query budget in both columns. Each column is the full trial: the hot-start pair, every query the model tried in order (held or refused queries included), then each held-out test item with the model's answer beside the correct output. The harness column adds fresh readings: before a query is sent, three fresh copies of the model predict its output; a query they all agree on is held once.
