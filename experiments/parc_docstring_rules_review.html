  overwriting existing colors.

**Inference.** Prefer strictly interior 4‑connected foreground blobs of size 2–10

test2_t18rule
Horizontal periodic pattern wrapping between halves.

Rule: a horizontally periodic motif occupies one half of the grid, with its axis row reaching one of the side edges (left or right) and NOT touching the opposite edge. The motif then "wraps" into the other half on the SAME side as the wrap edge, just shifted vertically into the other half. From there it continues across the other half all the way to the opposite grid edge. The periodic structure is preserved across the wrap.

Equivalently, parameterize the wave by an integer position x that increases
along its path from the input-half interior, out to the wrap edge, then jumps
across to the same edge in the other half and proceeds to the opposite edge:
    - Input half, wrap=right: col c -> x = c.            (col 0 interior, col W-1 wrap edge)
    - Other half, wrap=right: col c -> x = 2*W - 1 - c.  (col W-1 wrap edge, col 0 opposite)
    - Input half, wrap=left : col c -> x = W - 1 - c.    (col W-1 interior, col 0 wrap edge)
    - Other half, wrap=left : col c -> x = W + c.        (col 0 wrap edge, col W-1 opposite)

Cells are drawn at (axis_row + dr, c) iff (dr, x mod P) belongs to the motif M. The same period P and motif M apply to both halves; the axis row in the other half is at the same RELATIVE position within its half.

test2_t32rule
Bidirectional color mapping across a horizontal separator.

Rule:
- The grid is divided into a top and bottom section by a full grey row.
- Above the grey row, each row encodes a color correspondence: the uniform color on
  the left half maps to the uniform color on the right half. The mapping is two-way.
- Below the grey row are colored blocks placed entirely on either the left half or
  the right half.
- In the output, every bottom block is preserved in place and also recreated on the
  opposite half using the mapped color while keeping the same shape and row positions.
